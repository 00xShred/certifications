# CompTIA Security+ (SY0-701) Study Materials

A structured set of exam preparation notes aligned to the official SY0-701 exam objectives. Covers all five domains with definitions, practical scenarios, exam tips, and study checklists.

---

## Exam Overview

| Property | Detail |
|----------|--------|
| **Exam Code** | SY0-701 |
| **Questions** | Maximum 90 (multiple choice + PBQs) |
| **Duration** | 90 minutes |
| **Passing Score** | 750 / 900 |
| **Question Types** | Multiple choice (single and multiple answer), drag-and-drop, PBQs |

## How to Use These Notes

Each domain README is organized as follows:

1. **Acronyms Quick Reference** — table of all domain-relevant acronyms
2. **Objective Sections** (e.g., 1.1, 1.2) — each containing:
   - Key concepts and definitions in table or structured format
   - Comparison tables for easily confused concepts
   - Practical scenarios showing real-world application
   - Exam tips highlighting known traps and tricky distinctions
3. **Study Checklist** — granular, testable items to verify readiness per objective

---

## Study Approach

1. Work through each domain README in order (or prioritize by weight: D4 → D2 → D5 → D3 → D1)
2. Use the study checklist at the end of each domain to identify gaps
3. Review the `final_prep/` files in the final days before the exam
4. Practice with PBQ-style scenarios — the exam is heavily scenario-based
